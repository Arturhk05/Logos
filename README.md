# Logos

Uma plataforma de gerenciamento de incidentes que tem como objetivo centralizar e otimizar a comunicação e a resolução de problemas em tempo real. Com o Logos, analistas podem lidar com incidentes de forma mais organizada e eficiente, garantindo que as equipes de suporte possam responder rapidamente a qualquer situação crítica.

## Estrutura do repositório

| Pasta | Conteúdo |
|---|---|
| [`backend/`](backend/README.md) | API em Python (FastAPI) |
| [`docs/`](docs/) | Desafio, requisitos e decisões de arquitetura (ADRs) |

**Uso de IA:** o desenvolvimento contou com um assistente de IA (_Claude Code_) como par de programação, para discutir alternativas, revisar código e gerar testes. As decisões de produto e de arquitetura foram minhas e estão registradas nas ADRs. O `AGENTS.md` descreve as convenções do projeto para essas ferramentas.
